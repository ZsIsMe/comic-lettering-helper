# 自動預排版 Skill

目標是先完成可供人工接手的預排版，後續由人工精修。完成標記表示本輪已逐頁看圖並處理能確定的排版問題；一般疑點保留現況繼續，不建立待確認／待修改清單，也不因此保留整頁未完成。

## 範圍與執行

沿用 Codex 內建瀏覽器（IAB）的 `http://127.0.0.1:6008/#/prelayout` 及目前項目。頁數為導覽從 1 起算的自然排序，只處理指定範圍；無既有任務又未指定範圍才詢問。使用者要求暫停或討論時停止修改。

由目前主代理直接看圖、判斷、修改及驗證，不委派子代理；舊的 `@comic-proofreader` 呼叫亦同，除非使用者明確改變此要求。不改用其他瀏覽器，不以舊報告或完成標記代替看圖。工具失效按 Browser Use 指引恢復，不能恢復則回報阻礙，不走隱藏前端狀態或直接寫後端。

操作前讀 [WebMCP 操作與續作](references/webmcp.md)。公開工具用於精確批次修改，UI 用於看圖、導航及工具未涵蓋的正式編輯功能。完整工具結果留在執行環境，按該參考的「精簡回傳與截圖」輸出必要欄位；跨頁只延續共用規則、進度及當前未保存工作，不累積逐頁修改紀錄。

執行中遇到疑點、內容錯誤、需授權的刪框／修字或無法可靠排入等問題，先記錄頁號、文字 ID、原因及已保存狀態，保留該問題項目，繼續處理同頁其他可獨立判斷的內容與後續頁面；不要停下等待使用者回覆或逐項詢問。有疑點的頁面保存但不標完成，最後集中回報待確認項。這不授權擅自修字、刪框或猜測；若工具失效使後續工作均無法繼續，依上方恢復與回報規則處理。

## 排版標準

按「對應原文 → 主字大小與方向 → 語意換行 → 位置留白 → 顏色描邊」判斷，只改有明確問題的框。

1. **字級**：在相同有效縮放下匹配原文主字，排除注音。短譯文不因此縮小；同一／連通氣泡原則同字級，原文明顯不同才保留差異。先修正字級，再調換行與位置；不可為塞入氣泡隨意縮字；仍放不下就保留合理可讀的預排版，交人工後修，不反覆嘗試或另記待確認。
2. **位置**：先找到原文，再按實際氣泡形狀居中，排除尾巴。所有字、標點與描邊須有清楚留白，不能貼線；約半至一個主字寬可作起點，依原圖調整。偵測矩形不是氣泡邊界，弧線附近須特別看清。
3. **換行**：空間允許時不超過對應原文的行／列數，未知則看圖。按閱讀順序盡量避免後行／列比前行／列多超過 2 個主字，主動修正過長尾行；不拆詞、人名或英文單詞，不孤立標點或末尾一字。留白、避免超框及語意優先，必要時可增加換行。英文、數字、括號、省略號與拉長音按實際渲染判斷，不能只數字數。
4. **方向與角度**：跟隨原圖，不一律豎排；框外對白和音效也須檢查。擬聲詞直接移到對應位置；分散藝術字以既有框對應主要音效區，保持合理角度與可讀性，不要求重製字形，也不另外報告此類情況。介面使用 `rotate(-rotation)`，正值逆時針、負值順時針。
5. **顏色與描邊**：每框都檢查，包括描邊為 0 的項目。框外大型音效若變成對白大小的小直欄，須重新核對字級與方向；原文白字黑邊不能沿用對白的黑字白邊。放大辨識灰底、網點和細白邊；白底氣泡通常不需描邊，框外字依原文與背景可讀性判斷，黑字通常配白邊。移位、轉向或放大後重看背景，不靠粗描邊掩蓋殘文。

## 文字完整性與特殊頁

只調換行，保留字元、空格、標點與順序；不重譯、重設計標題或改圖片。撤回「更積極拆分」的泛化要求：拆框用於分開不同氣泡中被誤合併的文字，不因同一氣泡內文字較長、難以放入或想縮短欄高而拆框。其他拆框須有原圖明確的獨立文字層次依據，不自行擴大授權。同一氣泡已有多框，仍按整句統一字級、方向、欄距與視覺居中，不能各框分別居中卻讓整組偏移；語意換行不得孤立拉長音及其後標點（例如「——！？」）。經正式工具拆框後，按原閱讀順序串接、去除換行，須與原文字完全一致。沒有可靠拆框方法則保留現況，繼續其他框。

版權、目錄及署名頁按原圖資訊層級处理，不機械套用對白行長偏好。先辨識重複框、錯拆姓名與職銜，再排位置；同文不等於重複，須確認原圖只有一處對應。現有譯文缺字、錯譯或重複條目，按已有授權處理；未授權就保留原字，繼續處理可確定的排版，不記疑點清單，不影響本輪預排版完成標記。只有原圖不可用、整頁無法可靠對應，或使用者明確要求整頁跳過，才保留整頁未完成；交付時簡述未處理頁碼即可。獲准修字／刪框時用正式 UI，不把本次授權擴為未來權限。小字仍讀不清時不猜。

去字底圖只是輔助；計分板、隊名、比分、標籤等底圖內容消失或殘影，不屬於文字排版問題，不修補、不補字、不另備註。舊 BT Viewer 的固定描邊、偶數字級、作品例外及覆蓋規則不套用。

## 每頁流程與验收

- 確認項目、範圍、頁號／頁 ID、穩定文字 ID 與最新 token。以單頁彩色差異為預設判讀、修改及驗收畫面，不例行切原圖或關閉高亮。放大並捲動畫布，按閱讀順序逐個氣泡、逐個文字框核對；每個區域都必須看清原文、譯文、標點及完整氣泡邊界。不得以縮小全頁圖或快速掃視代替逐項判讀，即使該頁不修改也一樣。截圖可同時包含多個相鄰氣泡，但每個都須逐一確認；看不清就繼續放大或捲動。全部逐項看完後，可以使用縮小全頁圖驗收整頁關係。
- 優先使用適合寬度等可讀縮放，按閱讀順序一次查看相鄰區域；一般頁面可從上下兩次、適度重疊的截圖開始，若一張已足夠可少於兩次，文字密集、畫面過長、辨識不清或修改影響較大則增加次數。這是效率參考，不是固定次數或驗收標準；同一張圖中的每個氣泡和文字框仍須逐一核對。已看清且未受修改影響的區域不重截；合併導航、資料讀取與必要的畫面查看，避免僅為計數或保存狀態重複截圖。
- 先逐個檢查原圖所有氣泡，再逐個核對現有文字框，確認兩者對應、閱讀順序和文字完整性。遇到空氣泡，主動檢查該氣泡的譯文是否被合併在別的文字框；依原圖明確屬不同氣泡時，使用正式拆框功能分開並放回各自氣泡，保持字元與順序。不能可靠判斷或拆分時，記錄問題並保留該頁未完成，繼續其他內容。
- 逐框依標準判斷，記錄修改 ID 與理由，以完整氣泡為判讀和驗收單位；可合併提交已判斷清楚的欄位，但不以整頁批次修改為預設，不跨未看過的頁面盲改。修改後查看全部受影響區域及鄰近框線；分離區域分別看，小裁切缺上下文就擴大。
- 核對留白、字級、行列形狀、對應位置及樣式。零警報、`rendered:true` 或「可讀」不能代替目視驗收。利用已看清的頁面上下文檢查氣泡間比例、閱讀順序及框外文字；只有改動影響整頁關係或影響範圍不明，才補看全頁。已確認且未再受影響的區域不重截；無修改頁仍須逐框看圖，不設截圖張數上限而犧牲可讀性。
- 逐個氣泡和文字框都已看清並核驗，所有修改後的受影響區域也已在可讀放大畫面驗收，才可保存並標完成；無修改不等於已核驗。遇到無法看清、未核對或有待確認項，保存但不標完成，明確前往下一頁，避免循環。操作回傳失敗先查是否已生效，不盲目重送。每完成一小段簡報進度。
- 符合前述逐項核驗及完成標記條件後提交保存。中間頁使用工具支援的 `wait:false` 背景保存並以 `next_page_id` 進入指定下一頁，不逐頁等待寫入成功，也不加固定延時或反覆輪詢；最後一頁、暫停或交付前使用預設等待的保存，統一確認全部背景保存與完成標記。背景 pending 表示已提交，不能回報為已落盤；失敗保留草稿並處理，不盲目重送。保存後不重截同畫面，每完成一小段簡報進度。

## 保存與交付

用工作台草稿、自動保存與撤銷；一般校對不改程式、不重新偵測／匹配／匯入，不直接編輯伺服器 JSON。可唯讀備份指定頁狀態與修訂。

只保留續作所需的項目 ID、範圍、最後已處理頁及下一頁；暫停前確認背景保存全部完成，續作位置才記為已保存；每小段或暫停時更新一次即可。需要落檔時使用指定位置，否則放項目忽略目錄 `var/prelayout-reviews/<時間>/`。不逐頁寫修改 ID、理由、修訂明細、疑點或待修改資訊；使用者另行要求審計、用量或耗時分析時才收集詳細紀錄。不將漫畫資料加入 Git。

使用者修字後，重新 inspect 最新修訂作為本輪基準，保留使用者修改。

拆框當下核對字元完整性（去除換行，按原閱讀順序重組），不另做整批文字審計。結束以等待保存確認全部背景寫入及完成標記成功，再確認預排版進度，保留結果分頁與本機服務，簡報已處理範圍與續作位置即可；保存失敗或整頁未處理才說明，無須待確認、待修改清單或詳細修改報告。
