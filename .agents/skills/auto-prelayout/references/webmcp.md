# WebMCP 操作與續作

## 工具與狀態

依 Browser Use 文件連上 IAB 工作台，取得 WebMCP 工具並讀實際 schema；以下只記易錯處。頁面重載、工具變更或 handle 失效才重新取得。UI 用 cua_repl；DOM evaluate 僅唯讀，不注入 editor state、私有函式或 HTTP 寫入。

- `prelayout_inspect_page`：保留完整結果，確認項目、頁面、範圍、修訂、保存狀態及穩定 `_id`。寫入與導航使用最新 token，不用陣列位置代替 ID。
- `prelayout_patch_page`：同頁原子批次修改。`center` 是原圖像素，不能與 x/y 混用；text 只允許換行。套用共用人工撤銷與自動保存，不自動開對比。
- `prelayout_compare_page`：detail 可看最近一次修改前／後及原圖；多個 region 都須核驗，edited 返回畫布。裁切不足就擴大 padding；微小縮圖則回主畫布放大。刷新會失去修改前快照與當前撤銷。
- `prelayout_save_page`：省略 reviewed 只保存，true 標完成、false 取消完成。依實際 schema，中間頁用 `{token, reviewed:true, wait:false, next_page_id:下一頁ID}` 啟動背景保存並前往指定頁，不等待前頁寫入，也不靠固定延時判成功；接續使用回傳的下一頁資料及 token。背景狀態 pending／failed 須如實保留，失敗依工具提供的重試方式處理。最後一頁、暫停或交付前用 `{token, reviewed:true}`（預設等待）統一確認所有背景保存及完成標記。`advance` 會標完成並跳下一未完成頁，與 `next_page_id` 不同時使用；重校指定範圍用明確頁 ID，避免跳過舊已完成頁。舊前端 schema 未提供背景選項時沿用正式保存，不以未等待的 detached 呼叫繞過工具。
- `prelayout_navigate_page`：核對目標在授權範圍內，工具本身不限制範圍。
- `prelayout_set_view`：以單頁彩色差異（mode: overlay）作為判讀、修改及驗收畫面，comparison: false；利用顏色區分原文字與新文字，直接比較內容、字級、位置及留白。高亮本身不是正確性判定，仍須逐框目視。不要例行切換 original／final 或關閉高亮。旋轉錯誤可用 `prelayout_undo_page` 等既有撤銷功能恢復。

範圍在 UI「頁碼與範圍」設定後收起。UI 輸入先失焦，再用工具寫入；之後 inspect 更新資料。彩色差異模式在同一畫布辨識原文字與新文字；偵測框妨礙判斷時關閉。圖片及字型須載入後才判讀，source_line_count 為 null 就從高亮畫面辨識來源行列。讀不清先放大局部；使用者指定「不使用原圖對比」的測試期間，不切原圖、不關高亮，仍無法判斷則保留現況交人工後修，繼續其他框，不記疑點清單。

當前頁由連續畫布捲動位置決定，可能不同於右欄選取文字。導航交界、縮放、視窗尺寸改變或頁面提示出現後，重新核對頁號／頁 ID；目標已載入卻仍判前頁時稍向下捲，不固定套用捲動量。原位編輯也可能自動水平捲動，下一框按更新後畫面定位，不沿用座標。定位失敗先看 DOM／畫面，不重送同一失效定位。

## 精簡回傳與截圖

- 持續執行環境保留完整結果與頁碼表，僅輸出下一步需要的欄位。首次輸出項目、範圍與當頁狀態；每頁輸出穩定 ID、文字、字級、方向、角度、中心、顏色、描邊及來源行數。OCR、來源框與警報按判斷需要讀取。
- 修改後輸出 applied、rendered、頁面身分、新風險及變更值；背景保存後僅輸出當頁身分、待保存／失敗摘要及下一頁所需欄位；最終等待保存後輸出 revision、dirty、saving、reviewed 及背景任務是否全部完成。token 留在變數內，不反覆打印 pages 或整頁資料。
- 導航已帶目標頁資料就直接使用；有效的新 token 接續操作。僅缺欄位、頁面可能改變、UI 編輯、token 過期或結果不確定時重讀。WebMCP 足夠時不再輸出整份 DOM。
- 先檢查成功狀態與有效 JSON，再提取欄位；錯誤、新風險及部分成功不能省略，不以截斷字串隱藏尾部錯誤。失敗先確認是否已套用。
- 按氣泡讀清整句後修改、驗收；工具的批次能力只合併已有明確判斷的欄位，不代替逐氣泡判讀。不為每個欄位各截圖。相鄰變更合併檢查，分離區域分開看；需能讀清原文、譯文與完整框線。修改仍有問題只重查該區及鄰域；全頁關係改變或影響不明才補全頁。 沿用可讀的縮放，不例行縮小、重導航同頁再放大；只有可讀性或可見範圍不足才調整視圖。
- 保存修訂與已核驗版本一致時，用保存狀態確認即可，不重截同畫面；內容重新變動才重看。未修改頁無須製造修改後截圖。節省重複資訊，不降低視覺驗收。

## 正式 UI 的內容例外

取得明確修字／刪框授權後，可在側欄選取文字項並編輯「文字」或刪除；用最新 DOM 定位，刪除後序號會變，重新確認。失焦後 inspect 取得新狀態，不繞過 patch 的文字限制。

字面的反斜線+n（`\n`）不同於真正換行。已獲格式修正授權時，在正式文字欄修正、失焦保存，再用公開工具排版；只處理確定的標記，不刪其他反斜線或字母，並當下核對其餘字元保持。

混合字級拆框：雙擊開「原位編輯文字」，選取要獨立的文字後使用「分割」；inspect 取得新 ID，再設樣式與位置。新框可能排在陣列末尾，完整性核對須按原框閱讀順序重組。

## 每頁統計

一般預排版不做逐頁統計或另建紀錄。使用者要求耗時／用量分析時，才從現有執行紀錄累計工具呼叫、WebMCP 操作、截圖及重試；一次工具呼叫可含多個操作，不等於模型請求。不為計數增加瀏覽器請求。

需要 token 分析時再讀可取得的執行用量紀錄，分列未快取輸入、快取輸入與輸出；無法可靠分頁的部分列為共用／未分配。缺失值不當作零，不用工具次數估算 token；補校另列，避免混入原批次平均。

## 跨頁上下文

- 使用者修字後重新 inspect，以最新修訂接續，保留使用者修改。
- 每頁提交背景保存後直接接續指定下一頁，不逐頁等待或寫修改紀錄；拆框當下核對字元即可。下一頁不重印或重讀已完成頁的文字框、修改程式、截圖與逐框敘述。
- 跨頁保留項目／範圍、排版規則、使用者偏好與授權、最後已處理頁、下一頁、整頁未處理頁碼、當前未保存工作與背景保存狀態，以及仍有效的瀏覽器／工具參照。每小段或暫停時更新簡短續作位置即可。
- 續作摘要保留上述共用資訊及下一步，不複製逐頁修改清單或待確認清單。若壓縮發生於頁內，只保留該頁尚未保存的工作。
- 持續執行環境可用當頁變數接續新結果，避免為每頁建立長期保留的完整物件；只在需要暫停／續作時保存簡短進度。替換變數或停止重印不會移除已送入模型的歷史，不能宣稱翻頁便清空上下文，也不因省 Token 自行改用子代理或建立新任務。

## 重啟與中斷

暫停前等待全部背景保存與完成標記成功，再保留項目、範圍、最後已保存頁及下一頁。重啟後恢復原服務與 IAB，核對項目、範圍及保存狀態，再從續作位置接續，不重跑偵測、匯入或整批排版。

重新取得連線、工具 handle、資料及 token，不沿用舊選取或座標。操作中斷先查是否已保存，已保存且本輪已看過的區域不重做。完成標記表示本輪預排版已走查，供人工接手及定位續作進度。
