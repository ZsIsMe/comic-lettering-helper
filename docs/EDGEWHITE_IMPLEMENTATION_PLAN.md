## 3. 核心：自動尋找合適線位

### 3.1 輸入與座標

- 必須有活動參考線；水平線只接受上／下搜尋，垂直線只接受左／右搜尋。没有活動線或方向不匹配時不移線。
- 不要求預先選中塗白網格；已選網格不影響搜尋。
- 使用目前頁的原尺寸原圖，透明像素按白底處理；不讀取縮圖、螢幕截圖或已塗白預覽。
- 統一左上角原點及整數像素座標。灰階為 `floor((299R + 587G + 114B) / 1000)`，白色閾值為 `255 - tolerance`。
- 容差範圍為 0–255，預設 30；像素灰階大於或等於閾值才算空白。容差保存為使用者偏好。
- 網頁顯示、搜尋及輸出共用同一份規範化工作圖和尺寸；原始上傳另行保留。解碼、色彩、透明度和方向處理列入對照驗收，不能只因公式相同就宣稱跨平台逐像素一致。

### 3.2 搜尋規則

1. 從當前座標開始，包含距離 0，沿指定方向逐像素檢查，最遠 64 原圖像素；不反向搜尋。
2. 範圍同時受圖片內部及相鄰平行線限制：座標須在 `1…尺寸−1` 內，與相鄰線至少相差 1 像素。不能跨線、合併線或越界。
3. 使用垂直於活動線的參考線分段，分段邊界加入 0 和整個跨度；交叉座標去重並排序。像素分段採左閉右開區間，無交叉線時整條線是一段。
4. 每個候選位置逐段檢查：該段每個像素都符合白色閾值才算通過。不忽略深色噪點，不增加最短段長或內容支撐條件。
5. 候選以「完整空白段數」評分，段數越多越優先；段數相同時取距離最近者，包含當前位置。
6. 部分段通過仍繼續搜尋。只有全部段通過時，才可提早結束。
7. 全範圍零段通過，保持原位並顯示原因。最佳結果是當前位置，也保持原位並顯示通過段數。
8. 成功時移動整條活動線，保留線 ID、選區及其他線；不自動新增線、選格、塗白或導出。

關鍵例子：當前位置通過 1/2 段，往下 8 px 能通過 2/2 段，應移動 8 px；若整個範圍最多仍只有 1/2 段，應保持原位。容差 0 只接受純白；容差 255 時所有像素通過，線保持原位。

### 3.3 觸發、回饋與非同步保護

- 同時提供醒目的方向搜尋按鈕與鍵盤操作，按鈕只啟用符合活動線方向的兩個方向。
- Mac 使用 Option＋方向鍵；其他平台暫定 Alt＋方向鍵。僅在編輯區取得焦點、且非輸入欄位／彈窗時處理快捷鍵；保留按鈕作瀏覽器快捷鍵衝突時的操作入口。
- 狀態列顯示搜尋中、目標座標、移動距離、通過段數及沒有移動的原因；活動線與座標清楚標示。
- 搜尋暫定放入 Web Worker；只快取目前頁原圖灰階，以來源內容雜湊辨識，避免長時間阻塞拖曳或載入整本漫畫像素。
- 請求攜帶資料集合 ID、頁 ID、來源雜湊、活動線 ID 及編輯世代號。切頁、切線、改線、改選區、改容差或再次搜尋後，舊結果不得覆蓋新狀態；盡可能取消無效運算。
- 提供「撤銷上次吸附」及 Mac 的 Command＋Option＋Z。單步恢復上次成功吸附前的位置；其他編輯、切頁、切線或再次搜尋後失效，與現行模型語意一致。

## 4. 獨立頁面與操作流程

暫定流程：工作台小入口「邊緣塗白」 → 新建／重開邊緣塗白集合 → 上傳圖片 → 逐頁放線、搜尋、選格 → 保存 → 下載整批結果。

- 首頁只增加小入口；專用頁擁有清楚的返回入口、集合名稱、頁碼及保存狀態。
- 左側為可縮放、平移的編輯區，含四邊標尺、多條參考線及選區；右側為適合視窗的實際塗白预覽。
- 方向搜尋按鈕、白色容差和目前活動線座標放在編輯區主要工具列，避免藏在次級選單。
- 保留圖片上一頁／下一頁、保存、保存並下一頁、放大／縮小、適合視窗及 Navigator。
- 標尺可反覆拖出線，線拖出圖片外、雙擊或 Delete 可移除。普通方向鍵按原圖像素微調；線位不可因顯示比例失去精度。
- 點擊格子切換塗白；小幅點擊與放大後平移手勢分開判定。新增／刪除線清空選區，移動既有線保留選區；介面簡短提示先放線再選格。
- 上／下／左／右四個快捷槽保存絕對像素座標，不轉成距離邊緣或百分比；遇越界或重複位置按來源規則夾限／尋找附近可用像素。
- 預設縮放暫沿用桌面版的「適合視窗倍率」：1–5 倍；介面明示倍率基準，避免誤認為 1 倍就是原圖一比一。
- 每頁保存前提供完整預覽；吸附成功不代表所有格子都可安全塗白。尤其要能只清理角落廣告，保留同側出框筆畫。

路由暫採 `#/edgewhite` 及帶集合 ID 的子路由，使重新整理能直接返回獨立頁面；入口判斷優先於既有工作台的「記住上次項目」，避免自動跳走。正式 URL 待共用入口方案確定；若改用一般路徑，須一併處理目前 FastAPI 靜態服務的頁面回退。

## 5. 資料保存與輸出（暫定）

### 5.1 保存責任

使用 `<COMIC_DATA_ROOT>/edgewhite/<collection-id>/` 保存獨立集合。JSON 管理穩定頁 ID、原檔名、stem、自然排序、尺寸、來源雜湊、參考線、網格選區、編輯修訂及已保存輸出修訂；圖片另存。

- 原件、規範化工作圖、草稿、已保存輸出及可重建 ZIP 分開保存。清除選區可恢復原圖顯示，不能破壞來源。
- 參考線與選區在操作完成後自動保存草稿；「保存圖片／保存並下一頁」確認該頁輸出修訂。區分「草稿已保存」與「輸出已更新」，避免已有舊輸出時誤顯示最新編輯已輸出。
- 原子寫入新版本後更新 manifest；保存附帶預期修訂號。切頁／返回前完成草稿保存，保存失敗留在當前頁並可重試；保存並下一頁須等圖片保存成功。
- 下載時固定讀取快照，不混合新舊修訂；仍有未更新輸出的草稿時列出頁面，提供先保存再下載的明確操作，不默默忽略或採用草稿。
- 可重開及刪除自己的集合；刪除、保存和下載採集合鎖及 reader 引用，不能移除仍在保存或傳輸的資料。
- 不直接套用現有修圖的 overlay／other／edited 保存 API，避免意外將單純塗白標成 Mask 已準備或改動既有修復輸入。需要共用的檔案、鎖與下載工具再適度抽取。

### 5.2 匯入及完整輸出

- 第一版暫定接受 PNG／JPG／JPEG，支援文件夾第一層或多選；忽略 `._*`、拒絕重复 stem／無法解碼／無效尺寸，以自然排序保留閱讀順序。
- 圖片格式支持少於 Mac 版；TIFF、BMP、GIF、HEIC、WebP 是否納入首版留待確認，不默默略過使用者所選的不支援格式。
- 規範化工作圖暫定為原尺寸 sRGB PNG，透明處合成白底。帶旋轉方向資訊的輸入先依明確規則拒絕並提示整理；不默默轉向而讓舊線位失準。
- 結果 ZIP 暫定包含 `deal/<stem>.png` 及集合根層的 `edgewhite_guides.json`。未編輯頁以同尺寸工作圖直通，維持完整頁面集合；使用快速壓縮，避免逐檔下載。
- 輸出統一 PNG 是暫定的網頁調整，與桌面版依格式輸出 JPEG／TIFF／PNG 不同；不覆寫本機來源資料夾。
- 計劃提供桌面 `edgewhite_guides.json` 版本 1 的匯入／匯出：按原始完整檔名映射，保留座標陣列及 row／column 選區。檢查重複線、越界、無效格子與缺少圖片，不靜默套到不同頁。
- 舊 JSON 沒有尺寸與雜湊；匯入不能宣稱驗證了原圖身份。網頁內部格式補足這些欄位。可讀取的桌面 JSON 與可重新匯入的完整網頁集合封存須分開標識；後者是否列入首版待定。

## 8. 驗收案例與檢查

### 8.1 自動搜尋

- 四個方向各能找到第一個最佳位置；不反向、不越過 64 px 或相鄰線，距離 64 的有效位置可命中。
- 遠處兩段通過優於近處一段；三段中兩段優於一段；同分取最近，當前位置同樣參與評分。
- 部分段通過不能提早停止；全部段通過可停止；全範圍零段不動。
- 沒有交叉線、單像素分段、单個深色像素、淡灰與閾值恰好相等均有確定結果。
- 容差 0、30、255 及邊界值符合現行語意；輸入錯誤、零尺寸、非法方向得到可預期處理。
- 塗白選區、畫布縮放和平移不改變同一原圖及線位的搜尋結果。
- 快速連按、切頁、切線、改容差及移線後的舊結果不得回寫；撤銷恢復正確座標並按規則失效。

### 8.2 操作、保存與整合

- 多條線建立、移除及移動的選區語意一致，1 px 微調與預覽／輸出邊界一致。
- 右上廣告與左上正文伸出時，可拆格只塗右上，不要求整條頂邊塗白。
- 保持原尺寸，規範化工作圖的非選中像素不被塗白操作改動；來源原件雜湊保持不變。
- 重新整理、返回再進入、重新開頁恢復草稿；未更新輸出有提示，失敗保存不跳到下一頁。
- JSON 重新匯入、重複 stem、錯誤座標、兩個分頁同時保存、下載中刪除均有明確結果。
- 下載集合包含所有預期頁，未處理頁直通，沒有臨時檔或 AppleDouble 檔。
- 頁面可直接開啟，既有修復項目恢复／批次／下載仍可用；缺少 ComfyUI 或模型不阻止本工具的像素操作。
- 原圖只按目前頁建立像素快取；記錄真實圖片尺寸下的解碼、吸附耗時與記憶體，檢查重複切頁是否持續增長，不預先宣稱效能達標。
