# RF-DETR + MangaLens detection

The optional first stage uses two sequential model processes on an explicitly configured device: all RF pages, then all MangaLens pages. Production defaults to `cuda:0`; local runs may explicitly select `mps` or `cpu`. A third CPU process classifies the detected text and bubbles into RGBA solid overlay and remaining repair mask. Original RGB coordinates and protected manual edits are retained. Ordinary edits do not run these models. Missing models disable detection only; direct image/Mask repair remains available.

`config/detection-models.json` records the upstream URLs and SHA-256 copied from the reference project, not a new remote verification. Upload weights manually to the configured paths, or set `COMIC_RF_MODEL` and `COMIC_MANGALENS_MODEL`. No weights are included or downloaded. The worker verifies both weight hashes before inference. RF classes used for text removal are text and onomatopoeia; MangaLens balloon instance polygons guide conservative whole-bubble filling.

Use an isolated Python 3.12 environment with `requirements-detection.txt`, then install `rfdetr==1.7.0` with `--no-deps`, and set `COMIC_DETECTION_PYTHON` to its absolute Python executable. `COMIC_DETECTION_CONFIG` optionally selects another configuration file. RF-DETR 1.7.0 metadata requires pyDeprecate <0.8, while the reference supervision 0.30 requires >=0.9. The desktop reference explicitly used pyDeprecate 0.11.0. The separate `--no-deps` step is an intentional metadata override for that known combination, not a clean resolver lock; do not silently downgrade pyDeprecate. A target-host import and inference test is required before publishing. `opencv-python` satisfies the model packages’ declared dependency; the web application does not import its GUI support. The proposed CUDA dependency pins still require a target-host installation and real GPU acceptance; the macOS reference environment is not a CUDA compatibility guarantee. Do not install this list into ComfyUI or change its existing environment. The web service imports neither torch nor the optional model libraries. CUDA runs check available VRAM. MPS runs verify the Apple GPU is available and disable PyTorch operator fallback. CPU runs use CPU only. An unavailable requested device fails rather than silently choosing another one.

The engine's GPU gate reserves the GPU for the whole detection task. Before CUDA detection the service checks ComfyUI `/queue`, refuses if external work is running or queued, requests `/free` with model unloading, checks the queue again, then runs worker preflight including CUDA memory availability. This protects app-owned jobs; outside users must not submit directly to ComfyUI during a detection reservation. MPS and CPU detection do not contact ComfyUI or require it to be installed. ComfyUI is never restarted to free memory. After each model phase the entire child process exits before the next starts.

Task status and input page revisions persist under the project's `detections/<id>/`. Detected outputs remain separate until all selected pages pass output validation and revision checks. A server restart does not blindly replay GPU tasks. A surviving child PID is marked `recovery_required` and keeps the shared gate reserved; wait for it to exit (or stop it using normal host process supervision), then use the recovery endpoint. Dead interrupted tasks fail safely and preserve prior edits and completed caches. Cancel terminates and awaits the child before releasing the gate.

Core provenance and preserved source license are in `backend/imaging/NOTICE.md` and `backend/imaging/LICENSE`. The copied algorithms are independent of Qt and the desktop project's store. Model licenses remain governed by upstream publishers.

No weights were downloaded, no CUDA inference was run, and no remote environment was changed in this implementation. Required acceptance after weights are uploaded: one-page RF/MangaLens CUDA smoke test, a small multi-page batch including no-text pages, protected edits, and detection-to-ComfyUI model switching with timing/VRAM logs.

## Local model setup and validation

Copy the model JSON into an ignored local data directory, set `device` to `mps` or `cpu`, and set the two weight paths to existing files. Point `COMIC_DETECTION_CONFIG` at that JSON and `COMIC_DETECTION_PYTHON` at an existing compatible environment. Do not modify ComfyUI or copy model files into Git. The web button reports the configured device. Model caches use the application data directory.

On 2026-09-12 both real models completed a one-page MPS run using the existing macOS reference environment, with no downloads or dependency installation. The resulting project was exported, imported into the local workbench and opened with its detected text layer. This validates the MPS path only; CPU configuration has unit coverage but was not used for real inference in this run. See [local MPS validation](LOCAL_MPS_VALIDATION.md). CUDA acceptance remains pending.
