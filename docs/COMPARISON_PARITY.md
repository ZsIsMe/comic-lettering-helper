# 比較合成操作對齊

本輪僅本地。對照原工程 workflow_compare_ui.py。

- 矩形為預設；左鍵候選畫布採用該組差異 Mask，右鍵在任何模式都拖框回到底圖，中鍵同步平移。
- 各候選面板可以交換顯示來源、整組採用，面板右下可拖動寬度；普通滾輪以滑鼠位置縮放。
- 黃線可直接拖動，原圖顯示範圍所有面板同步；M 切換差異 Mask 深淺及輪廓，深色已採用、淡色未採用，成品不染色。
- 「重設本頁」收納恢復底圖與重新採用第一組；提供差異閾值、最小區域、Mask 擴大及重算。
- [ / ] 調筆刷，Ctrl/Cmd+Z 及 Shift+Z 撤銷重做。
- 編輯中的預覽即時更新像素；自動保存後主預覽顯示後端同一羽化輸出。不是宣稱筆畫中已即時計算完整羽化。
- 第一張「合成結果」成功載入並繪製後自動確認；載入失敗不確認。編輯保存後待新成品顯示再確認。移除重複的已保存成品與確認按鈕，全部頁面確認後才能輸出；匯出不再偷偷確認未看過的頁面。
- 合成結果面板只供查看、縮放和平移；直接在候選上框選採用，不使用全局來源選單。
- 切頁保持工具、筆刷、面板順序、原圖分隔位置及縮放設定，畫布區固定高度。

仍有刻意保留的網站契約：只使用當次修復記錄的候選，沒有額外引入模型或任意外部候選；修改Mask參數保留既有採用分配，新採用像素仍由後端驗證。面板來源交換避免同一候選重复顯示。
