# 比較合成操作對齊

本輪僅本地。對照原工程 workflow_compare_ui.py。

- 矩形為預設；左鍵候選畫布採用該組差異 Mask，右鍵在任何模式都拖框回到底圖，中鍵同步平移。
- 各候選面板可以交換顯示來源、整組採用，面板右下可拖動寬度；滾輪操作與準備頁一致：普通滾輪平移，Cmd／Ctrl＋滾輪水平平移，Option／Alt＋滾輪居中縮放。
- 黃線可直接拖動，原圖顯示範圍所有面板同步；M 切換差異 Mask 深淺及輪廓，深色已採用、淡色未採用，成品不染色。
- 「重設本頁」收納恢復底圖與重新採用第一組；提供差異閾值、最小區域、Mask 擴大及重算。
- [ / ] 調筆刷，Ctrl/Cmd+Z 及 Shift+Z 撤銷重做。
- 編輯中的預覽即時更新像素；自動保存後主預覽顯示後端同一羽化輸出。不是宣稱筆畫中已即時計算完整羽化。
- 第一張「合成結果」成功載入並繪製後自動確認；載入失敗不確認。編輯保存後待新成品顯示再確認。移除重複的已保存成品與確認按鈕，全部頁面確認後才能輸出；匯出不再偷偷確認未看過的頁面。
- 合成結果面板只供查看、縮放和平移；直接在候選上框選採用，不使用全局來源選單。
- 切頁保持工具、筆刷、面板順序、原圖分隔位置及縮放設定，畫布區固定高度。

仍有刻意保留的網站契約：只使用當次修復記錄的候選，沒有額外引入模型或任意外部候選；修改Mask參數保留既有採用分配，新採用像素仍由後端驗證。面板來源交換避免同一候選重复顯示。

準備與編輯以圖片空間優先：頁面欄預設收起，可在原有工具列展開；PageUp／PageDown 切頁前保存，輸入框、彈窗、局部視窗及隱藏工作區不攔截快捷鍵。首尾不循環，長按不連跳。

填色預覽可選右側、Mask 下方或收起；同一瀏覽器保存布局偏好，切圖及重新開啟沿用。切換布局不更改圖層、撤銷記錄或手動縮放。

準備頁採緊湊工具列：頁面下拉選擇及灰黃綠計數常駐，點狀態篩選切頁範圍；側欄改為下拉列表，導出在更多選單。工具與操作並排，縮放在圖片上方，靜態計時說明只在偵測運行時顯示。

填色預覽固定開啟圖像修補標記，不再顯示勾選項；透明度與標記色移至上方共用控制列，預覽圖不再單獨佔用控制列。

準備頁滾輪對齊原程序：普通滾輪平移、Cmd/ Ctrl + 滾輪水平平移、Option/Alt + 滾輪縮放。按使用者要求縮放改以圖片中心為準；小於視窗時雙向居中。預覽初始值重設為右側，之後仍記住三選一布局。

比較合成同樣取消左側頁面欄，使用上方下拉選頁、前後箭頭及確認數量；可篩選待確認／已確認，PageUp／PageDown 按篩選範圍切頁，導航前完成保存。

## 三種正式比較模式

- 多圖對比：保留原有整頁候選、矩形／筆刷與精細混合。
- 整體＋局部：上方整頁合成結果，點框線選修補區域，下方並排比較採用。
- 區域卡片：逐區排列底圖與可用候選，提供整頁回看。
- 同一瀏覽器的 `comic-compare-layout` 記住模式，切換前 flush；畫布共用同一個編輯器的來源分配、撤銷歷史、保存與輸出。單純切換不寫新分配。
- 區域由候選差異 Mask 及既有採用像素分組；24px 粗網格連通與重疊合併，裁切額外保留40px上下文。只用來導航，不是新偵測或品質篩選。
- 採用候選只改該區內、該候選允許的像素；其他混合來源保留，標記為混合來源。底圖操作只恢復區內修補範圍。
- 本地隔離副本驗證採用→保存→切換模式後分配檔雜湊及修訂號完全相同，重新載入保留區域卡片模式。62項前端測試與195項後端測試通過；未部署遠端。

比較視圖細節：多圖對比的原圖比例移到候選圖片正上方，分隔線頂部增加倒三角，所有面板控制列固定高度以對齊圖片起點。局部候選採用後以綠框、綠底標題及勾號顯示；整體＋局部預設適合寬度，可縮放、滾動及 Cmd／Ctrl 拖動平移。

整體＋局部提供大型上一區域／下一區域按鈕與 ←／→ 快捷鍵，切換後定位區域；首尾不循環，長按不連跳。輸入框、選單、彈窗、隱藏工作區或忙碌時不攔截。PageUp／PageDown 仍用於切換頁面。

區域卡片的合成結果為可拖動懸浮窗，不再佔右側欄寬度；拖動標題移動，支援收起／展開與放大查看。記住視窗位置並限制在可見範圍內；標題聚焦後方向鍵也可移動。整體＋局部的適合寬度／整頁以深綠底白字區分選中狀態。
