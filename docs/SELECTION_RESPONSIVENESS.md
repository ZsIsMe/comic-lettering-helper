# 修圖選區互動驗證（2026-09-20／21）

## 範圍與原則

分支 `codex/selection-responsive`，從 `96d3b02` 建立獨立工作樹。修改修圖第一部分及局部副本的 edit 模式；不修改其他工作樹、預排版、第三部分候選合成或 GPU 工作流。

左側輸入優先：拖曳期間只更新幾何輪廓，正式像素處理與右側重繪可延後；正式操作不能丟失或錯序。這一版採用 SVG 輪廓 + Canvas/ImageBitmap + module Worker，尚未採用 WASM。Worker 內仍保留原有全圖運算與有上限的歷史快照；更小的記憶體占用、局部區塊計算及 WASM 需另按實测瓶頸決定。

## 實作

- 高頻移動只記錄原圖座標；畫筆保留可用的 coalesced events。矩形、畫筆、套索完成時才提交正式指令，取消不進歷史。
- Worker 持有正式圖層、採樣來源與歷史，依序處理編輯、撤銷、重做、局部合併及保存快照。PNG 編碼也在 Worker，快照完成前後續指令不得超越。
- 左側獨立 SVG 顯示正在操作和等待中的輪廓。預览最多一個在途请求，後續需求合併；過期 ImageBitmap 釋放。操作中不替換完整像素畫面，待手勢／套索結束才呈現最新有效畫面。
- 保存以 UI 提交版本為屏障，等待已接受的指令；保存期間又有提交則繼續保存。未完成手勢仍阻止離頁，但不妨礙已保存版本清除舊的保存中狀態。Worker 致命錯誤不回報保存成功。
- 主執行緒預先計算佇列末端的撤銷／重做數量，避免快速操作或空撤銷產生錯誤狀態。

## 獨立驗證分工

使用 3 個 Sol high 子代理：A 檢查左側互動並建立瀏覽器測試頁；B 實作及檢查 Worker、失敗處理和排程；C 獨立加入像素一致性／排序／生命週期測試並審核整合。主代理整合程式，另外在獨立 IAB 頁面完成互動及保存重開測試。

審查修正包含：Worker 失敗後新請求不能永久等待；空撤銷不製造保存版本；完整預覽畫面不搶佔正在進行的手勢；保存完成與新手勢交錯時正確解除舊保存狀態。

## 瀏覽器測試方法與證據

啟動前端 Vite 後開啟 `/tests/selection-responsive-browser.html?workerDelay=1000`。預設合成測試圖為 2048 × 3072，`preset=square4k` 可用 4096 × 4096。頁面使用真正的 RasterEditor；Worker 回覆延後 1000 ms，讓正式結果刻意落後左側操作。它不連接使用者項目，也不提交伺服器資料。

頁面提供開始／讀取量測、額外 Worker CPU 壓力、保存及保存並重開。量測指標是 pointer 事件到下一次 SVG DOM 更新，不代表實體螢幕的 photon latency。初始解碼、初始化、首次全圖預覽需要先完成，再開始暖機後量測。

主代理 IAB 驗證：2048 × 3072、1000 ms Worker 回覆延遲、兩筆連續畫筆。19 個 pointer-to-SVG 樣本約 12.9–40.5 ms，量測區間無 >50 ms 主執行緒 long task。該自動化瀏覽器 rAF 約每 41.7 ms（約 24 Hz），因此此結果證明輸入沒有跟著 Worker 等一秒，不能宣稱已驗收 60 FPS。另一次完整流程連續畫兩筆、撤銷第二筆、保存並重開，畫面正確只保留第一筆，保存狀態正常。

子代理 A 的獨立 Chrome 補充測試把 Worker 回覆延後 3000 ms：2048 × 3072 畫筆 10 樣本為 4.7–47.8 ms、矩形 9 樣本為 19.2–45.4 ms、套索 6 樣本為 5.7–49.2 ms；結果回來前介面仍顯示正在處理。4096 × 4096 畫筆 10 樣本為 8.3–63.3 ms，矩形 10 樣本中 9 個為 7.9–46.9 ms，但有一個 144.7 ms 離群值；部分量測也記錄到長任務。瀏覽器擴充控制和測試傳輸會干擾計時，尚未完成長任務歸因，因此只能確認互動不等待 Worker，不能據此宣稱大圖完全不卡。A 的 Chrome 真圖第 7 頁上傳因檔案選擇器停滯未完成；真圖瀏覽器證據由主代理 IAB 測試提供，B 另做真實像素核心比對。

## 發布限制

尚未部署、推送或建立 Tag。尚不能將本機合成圖的自動化測試等同所有實際漫畫、硬體、瀏覽器和 AutoDL 代理的性能驗收。正式發布前需在實際 URL 測試同源 module Worker 載入、OffscreenCanvas 與 PNG 保存；本版不需要 SharedArrayBuffer 或 COOP／COEP。


## 魔法棒與畫筆追加修正（2026-09-21）

使用者回報點擊等待太久、懸停預覽消失。舊測試頁 `workerDelay=1000` 在每次回覆加入一秒延遲，且舊 UI 每次 hover 都使正式 render 世代失效。現在正式 left/right 與 magicLeft 分離，hover 只作廢 magicLeft；提交立即排程 render，不再等待 metadata 回傳才發起下一步。魔法棒预览預設開啟，可關閉並記住偏好；離開或關閉立即隱藏疊層。測試頁默认延遲為 0，可即時切換慢速模擬，關閉也釋放排隊回覆。

Worker 單項快取包含 revision、seed、容差、擴展、操作、類別、ROI 與 intersectOffset。對相同預覽直接提交可採用已算好的 next layers；init、commit、undo、redo、merge 使快取失效。新增測試驗證全部 key、失效路徑、乾淨 frame 與原核心逐像素一致，回收測試包括第三張 magic bitmap。

Sol high 子代理實測同一真圖：第 7 頁白區 solid expand=0 正式冷計算 140.70 ms → 預覽命中提交 2.25 ms；expand=16 為 399.03 → 2.47 ms。第 16 頁測點為 78.05 → 3.72 ms、337.52 → 2.38 ms。4/4 結果逐像素一致。這些是 Node 核心耗時，不包括瀏覽器合成／傳輸，也不代表首次預覽已只需數毫秒。

主代理在 IAB、真實 16.jpg、人工延遲 0 ms、容差 28／擴展 16 實際看到白底文字區綠色懸停，點擊後變為正式粉色待修補標記，關閉預覽立即隱藏。首次瀏覽器量測中一次預覽後點擊到正式 canvas 更新約 262 ms；這不是核心快取耗時，也不能據此聲稱所有點擊都在此時間完成。新的 `pointerToCanvasFrame` 與 pointer-to-SVG 分列，前者是 pointerup 到正式 canvas 提交的時間，並非螢幕實際出光時間；拖曳案例不能拿它當 pointerdown 到完成的延遲。

畫筆提供 1–200 px 滑塊／數字雙向同步、每次 4 px 的 `[` 縮小與 `]` 放大，工具列顯示文字提示。快捷鍵不攔截文字輸入或 Ctrl／Cmd／Alt 組合。IAB 實測 16→20→16，滑塊按右方向鍵一步變 17，數字改 40 後滑塊亦為 40。
