## 瀏覽器操作驗證

使用臨時目錄中的合成色塊圖片，沒有使用真實 GPU 候選或使用者圖片。

1. 畫布繪製 Mask、自動保存、撤銷、保存與重新載入。
2. 兩頁全黑 Mask 選擇三套工作流，直接完成並保留六張候選；進第三部分兩頁自動確認。
3. 合成測試候選中局部採用不同來源，保存來源分配；修改羽化至 2 px、確認並導出包含兩頁的成品 ZIP。
4. 重新載入後確認狀態、來源分配與羽化設定保留；窄視窗下項目與工具列正常排列。

正式羽化在伺服器保存後預覽及導出執行。互動畫布先顯示直接採用的像素邊界，不表示已套用羽化。
