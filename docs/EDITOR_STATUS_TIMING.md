# 編輯頁狀態與參考時間

左側只顯示檔名：灰色表示尚未準備 Mask；黃色表示目前 Mask 含待修補像素；綠色表示已處理且沒有待修補像素，不表示第二部分模型已生成。對照原工程 solid_inpaint_ui.py 的 other_pixels 判定。保存前由畫布即時更新，保存／重新開啟由目前 Mask 判定；舊項目不需遷移。

縮放提供加減、原尺寸、百分比、適合視窗，以及 Cmd／Ctrl＋滾輪（觸控板 pinch）。左右画布使用同一縮放值，原圖座標及輸出尺寸不變。

初始時間估算採保守值：準備 20 秒＋每頁 8 秒，單頁約 28 秒。2026-09-12 CUDA 合成單頁實測約 28 秒；本地 21 頁 MPS 歷史日誌 RF／MangaLens／分類中位每頁分別約 0.805／0.12／1.883 秒。8 秒是預留影像尺寸與設備差異的工程估算，不宣稱是 CUDA 多頁實測值。模型按階段整批執行，因此「第一張合計」是單頁作業参考，不承諾多頁任務在28秒時已發布第一張。未載入圖片大小、設備負載及排隊差異時僅作粗估。

計時以服務端 created_at 為基準；終止後停在 updated_at，刷新可恢復。超過預估時顯示仍在處理，不假裝剩餘0秒即將完成。
