# 工作流輪次本地介面預覽

此入口供確認交互設計，不需要 ComfyUI。它讀取既有項目與結果的縮小副本，狀態獨立保存在瀏覽器 localStorage，不修改項目、提交 GPU 任務或生成 PDF。

## 啟動

在倉庫根目錄執行，替換為已有本機項目的路徑：

```bash
.venv/bin/python scripts/prepare-rounds-preview.py --project /path/to/projects/project-id/project.json --jobs /path/to/jobs
npm --prefix frontend run preview:rounds
```

開啟 `http://127.0.0.1:5175/previews/repair-rounds.html`。素材位於忽略目錄 `var/rounds-preview/assets/`；準備腳本只讀原始項目，無法解碼的既有結果會提示並跳過。

## 可操作範圍

- 獨立「選擇執行圖片」彈窗，初始全選，可搜尋、全選、取消全選；原圖疊加半透明粉紅色當前 Mask，不提供 Mask 編輯。
- 工作流輪次以 `Flux_0930143022` 格式命名，同一模型可選多輪比較。缺少本頁結果時顯示空缺。
- 輪次列表的「加入比較／已選中」只切換選中狀態，可再次點擊取消；點「前往比較合成」才進入比較，未選輪次時停用。選中行以色塊和勾號提示。
- 準備頁「下一步」及預覽「前往比較合成」使用 48px 高的主色按鈕。
- 「加入下一輪」把全選改為當前頁，之後追加去重；返回批量修復後再手動開始。
- 多圖、整體＋局部及區域卡片共用採用結果；切頁和隱藏比較對象保留已選合成。
- 開始按鈕建立標記為「模擬」的輪次，沿用已有示範圖片。這不是新推理結果，Qwen 示範亦可能沿用其他模型的圖片。
- PDF 文案只顯示本次提交的圖片與工作流範圍，不實際製作 PDF。

預覽不包含正式後端的部分頁面快照、跨輪次合成持久化或生成服務串接。既有正式項目頁仍使用原接口。確認設計後才將這些契約接到正式流程；本頁不能作為 GPU 或正式數據遷移驗收。
