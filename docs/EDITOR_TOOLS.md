# 第一部分編輯工具

所有選區以原圖像素計算。左側為 Mask／原圖，右側即時顯示填色和待修補；顯示透明度不改導出資料。先選目前類別：F1 純色填充或 F2 待修補。

| 工具 | 操作 |
| --- | --- |
| 矩形 | 添加、減去、局部交集；含拖曳起終點 |
| 畫筆 | 添加、減去、局部交集；筆刷大小，整筆結束形成一次撤銷 |
| 魔法棒 | 添加、減去、選區內部、選區＋選區內部；容差 0–100（預設 28）、擴展 0–80 px |
| 套索 | 添加、減去、局部交集；左鍵逐點，雙擊／Enter 閉合，Backspace 退點，Esc 取消 |
| 局部視窗 | 矩形框選後進入獨立副本；詳見下文 |

添加改目前類別，並清除重疊另一類別；減去只清目前類別。局部交集僅裁切本次選區碰到的既有連通區，未碰到者保留；交集偏移為正時擴展、負時收縮。

魔法棒沿原圖固定 seed 顏色作 8 連通選取。「選區內部」添加被本次選區包圍的孔洞，例如白色氣泡包圍的文字；「選區＋選區內部」同時添加選區本身。移入畫布先顯示實際新增（綠）／移除（紅）範圍，點擊才套用。預覽與點擊使用同一算法，容差和擴展設定不直接保存像素。

## 框選快捷操作

- 右鍵拖曳：清除框內純色填充及待修補 Mask，保留原圖，並記錄人工排除。
- Cmd／Ctrl＋右鍵拖曳：把另一類 Mask 的框內部分轉到目前類別，從原類別移除。
- 「清除框內 Mask」「從其他轉入」按鈕：選擇後改用左鍵框選，方便觸控板操作。
- Cmd／Ctrl＋左鍵拖曳或中鍵拖曳：平移；F4 適合視窗。
- F5–F8：矩形、畫筆、魔法棒、套索；F9 添加、F10 減去、F11 局部交集（魔法棒不適用）、F12 轉入。
- Cmd／Ctrl＋Z 撤銷，Cmd／Ctrl＋Shift＋Z 重做。

## 局部視窗

以目前類別及當前草稿建立副本，含左右預覽、矩形／畫筆／魔法棒／套索、撤銷／重做。可輸入 X、Y、寬、高，外擴／內縮 32px、重設；只有「調整邊框」模式可以拖藍框，範圍不越出圖片。改範圍會清除副本的撤銷紀錄，避免沿用舊邊界。

所有繪圖只作用於藍框內，魔法棒也限制在框內尋找連通區。子視窗的「更新副本」不保存到伺服器；取消完全丟棄副本，套用只回寫最終範圍並形成一次主頁撤銷。主頁自動保存後可重開繼續編輯。未套用的副本刷新／關頁會提示。

## 2026-09-12 本機驗證

參考原工程 `solid_inpaint_ui.py` 的選區、魔法棒、孔洞、局部交集與 LocalEditDialog，未引入 Qt 依賴。畫筆局部交集、Cmd＋右鍵轉入是本輪明確新增的操作。

- 純函式測試涵蓋首層選圖、雙側预覽、局部 ROI、圖層互斥與轉入、重新填色、孔洞、局部交集、不可變預覽、套索邊界。
- 20 組隨機 Mask 的局部交集／正負偏移與原 OpenCV 環境逐像素一致。
- 本機 1080×1536 粗測：魔法棒約 92ms、局部交集約 117ms（算法單獨計時，不是整個 UI 的效能承諾）。
- 使用獨立本機服務與 400×300 合成圖片，沒有修改使用者項目：矩形 101×81 得到 8181 像素；右鍵清除與 Cmd 右鍵轉入各修改正確像素；魔法棒孔洞選出兩個 16×56 文字塊（1792 像素），預覽不生成修訂。
- 套索閉合後保存；畫筆局部交集將碰到的文字區塊縮為 178 像素，未碰到的文字仍為 896 像素。
- 局部視窗左邊界由 X=32 拖至 X=42，寬由 129 變 119；取消仍為原修訂 5。套用增加 189 個待修補像素並自動保存修訂 6，一次撤銷回到相同原像素（修訂 7）。
- 只修改編輯／預覽層，不需要重新執行偵測或三套修復模型；AutoDL GPU 驗收狀態不變。

最終檢查：24 項前端測試、77 項後端測試、ESLint、正式 Vite 構建與 git diff --check 均通過。隔離測試服務已停止；16008 本地服務沿用最新靜態構建，使用者刷新後生效。未提交或推送。
